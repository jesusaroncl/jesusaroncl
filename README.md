# 🚀 Sobre mí

Soy **Bachiller en Ingeniería de Sistemas de Información por la Universidad Peruana de Ciencias Aplicadas (UPC)**, orientado al desarrollo de soluciones tecnológicas, análisis de datos y optimización de procesos empresariales.

Cuento con experiencia participando en proyectos del sector privado y como profesional freelance, desarrollando soluciones digitales mediante el uso de tecnologías modernas, bases de datos y metodologías orientadas a la eficiencia.

Me especializo en transformar necesidades del negocio en soluciones tecnológicas funcionales, integrando conocimientos de:

- Desarrollo de software.
- Análisis y gestión de datos.
- Diseño de bases de datos.
- Desarrollo web.
- Automatización de procesos.
- Implementación de soluciones empresariales.

Mi objetivo es formar parte de equipos donde pueda aportar conocimientos técnicos, capacidad analítica y una visión orientada a la innovación y mejora continua.
